録画 -- SD -- Wi-Fi -- USB --

ライブ映像

状態

録画ファイル

AVI（MJPEG）形式です。PC では VLC などで再生できます。「再生」はブラウザ内で再生します（音声なし）。

カメラ・録画設定

USB Webカメラ(UVC)は 1280x720 として認識されます。解像度を HD 以外にすると、PC 側アプリによっては映らないことがあります。

ネットワーク

同じ Wi-Fi 内からは http://dashcam.local で、本体のアクセスポイントに接続した場合は http://192.168.4.1 またはどのホスト名でも開けます。

見た目のカスタマイズ（SD カード）

SD カードの www フォルダに保存され、/assets/ファイル名 で参照できます。 custom.css を置くと自動で読み込まれます（例: :root { --accent: #e5484d; }、画像は url(/assets/img/bg.jpg)）。 対応形式は CSS・画像・フォント（1 ファイル 2MB まで、ファイル名は英数字と _ - .）。 表示が崩れたときは /?nocss で開くと custom.css なしで表示されます。

メンテナンス

「USB書き込みモード」では次の1回だけ USB Webカメラを無効にして起動し、USB 経由の書き込み・ログ表示ができます。本体の BOOT ボタンを 3 秒長押ししても切り替わります。
